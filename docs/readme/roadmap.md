### **🎯 Objetivos**

- Implementar as classes base do projeto:
  - `Personagem`
  - `Inimigo`
  - `Missao`
  - `Jogo`
- Utilizar conceitos fundamentais de POO:
  - Construtores (`__init__`)
  - Atributos
  - Métodos
- Criar o menu inicial do jogo com as opções:
  - Criar personagem
  - Encarar missão
  - Salvar / Carregar jogo
  - Sair

## **📗 Semana 2 — Regras, Coleções e Funções**

### **🎯 Objetivos**

- Utilizar **listas** e **dicionários** para organizar:
  - Inimigos
  - Missões
  - Itens
- Criar funções auxiliares para modularizar o código.
- Usar o módulo **`random`** para:
  - Sortear inimigos
  - Sortear missões
  - Sortear itens
- Implementar o sistema de inventário:
  - Itens de cura
  - Itens de mana
- Validar interações do jogador usando condicionais:
  - Verificar escolhas
  - Restringir ações inválidas
- Exibir dados e feedback do combate:
  - HP atual
  - Dano causado
  - Dano recebido
  - Turnos de combate
  - Vitória ou derrota

### **📦 Entregável**

✔ Versão aprimorada com múltiplos inimigos, missões variadas, inventário funcional e logs de combate por turno.

## **📙 Semana 3 — Polimorfismo, Herança e Persistência**

### **🎯 Objetivos**

- Criar subclasses especializadas para o jogador e inimigos:
  - `Guerreiro`
  - `Mago`
  - `Arqueiro`
  - Chefes com habilidades únicas
- Implementar métodos sobrescritos:
  - `atacar()`
  - `habilidade_especial()`
- Implementar o sistema de **salvamento e carregamento** com JSON.
- Registrar logs de eventos importantes:
  - Vitórias
  - Derrotas
  - Itens coletados
  - Turnos de combate
- Aplicar **polimorfismo** :
  - Mesmo método → comportamentos diferentes entre classes.

### **📦 Entregável**

✔ Versão final do jogo, com:

- Hierarquia de classes completa
- Polimorfismo funcional
- Combate completo
- Persistência com JSON
- Sistema de logs
